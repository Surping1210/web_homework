# 校园水文水质智能监测系统 (Web 前端课程大作业 / 综合实训提交)

本项目为基于纯原生 Web 前端技术（HTML5 + CSS3 + 原生 JavaScript）精心设计的校园水文水质物联网综合监控与智能治理联动仿真平台。

---

## 📋 作业设计与提交规范说明

根据课程考核要求，本项目已完全遵循并实现以下规范：

### 1. 项目文件结构清晰规范
- **`index.html`（HTML 主入口文件）**：
  采用 HTML5 标准语法，严格按照 `h1`~`h6` 标题层级组织，包含语义化标签（`<header>`, `<nav>`, `<main>`, `<section>`, `<aside>`, `<footer>>`）、无序列表 (`<ul>`)、有序列表 (`<ol>`)、数据表格 (`<table>`)、各种交互表单 (`<form>`) 以及多媒体图片 (`<img>`)。
- **`css/style.css`（独立 CSS 文件）**：
  采用独立外部样式表，采用现代清新浅色科技调色板，模块化管理 CSS 自定义变量、盒子模型、定位（`fixed` / `sticky` / `relative` / `absolute`）、Flexbox 弹性布局、CSS Grid 网格布局、表格表单美化及响应式媒体查询。
- **`js/main.js`（独立 JavaScript 文件）**：
  纯原生 Vanilla JavaScript，无任何外部库依赖。负责系统全流程逻辑：包含实时传感器动态推演、Canvas 高帧率水质波形曲线引擎、声光报警器、双模闭环设备自适应调控、阈值配置双向绑定、历史数据分页与 CSV 导出、用户角色权限（管理员 / 访客）控制等。
- **`assets/`（素材文件夹）**：
  独立归档各类媒体与矢量素材（`assets/images/`），包含站点浮标实拍照、明渠水文站实拍、传感器节点图、系统闭环拓扑结构图与校园全域孪生图。

### 2. 代码缩进整齐，关键位置添加详尽注释
- 全工程代码严格采用 2 空格或 4 空格统一对齐，标签严谨闭合；
- 关键算法（如水质等级综合评价算法、Canvas 视网膜高清自适应折线图平滑贝塞尔曲线、Web Audio 音频振荡器、双模自适应调控逻辑等）均附有详尽的中文原理与参数注释。

## 🚀 本地运行方式（两种模式均支持）

### 模式 A：最简双击直接运行（无需安装任何环境，老师/助教批改推荐）
1. 解压项目压缩包；
2. 直接双击打开根目录下的 **`index.html`**；
3. 即可在 Chrome、Edge、Firefox 或 Safari 浏览器中完整体验全部交互功能、动态图表与设备控制。

### 模式 B：现代工程化启动（可选）
本项目同时保留 Vite 工程化支持：
```bash
# 1. 安装依赖
npm install

# 2. 启动开发服务器
npm run dev

# 3. 生产环境打包构建
npm run build
```

## 🎯 系统核心功能概览
1. **实时物联网遥测看板**：水温、pH值、溶解氧(DO)、浊度、水位、电导率、流速及微气象实时刷新与异常变色预警；
2. **动态水质趋势折线图**：HTML5 Canvas 纯原生双缓冲高帧率绘制各指标历史波形；
3. **设备联动控制中心**：支持自动阈值联动与人工手动接管双模式，联动增氧曝气机、循环砂滤泵、中和投药机与防汛液压升降闸；
4. **阈值参数自定义配置**：支持按地表水国标（GB 3838-2002）录入各指标基准区间；
5. **历史遥测台账表格**：支持数据翻页查看、CSV 表格导出与清空；
6. **站点实景画廊与相册**：支持多站点现场照片浏览与本地替换预览；
7. **用户角色体系**：
   - 超级管理员：账号 `admin` / 密码 `123456`（全功能权限）
   - 研学访客：账号 `guest` / 密码 `123456`（只读权限）
